# PPT演讲稿 (ppt-speech-fusion)

会议结束，整理纪要太耗时？丢入录音和PPT，瞬间输出专业演讲复原稿PDF——上半页为通顺演讲叙述，下半页为原版幻灯片，逐页精准对齐。Whisper 转写 + 智能配页 + 自动自检，从录音到成品一步到位。

## 安装

### WorkBuddy
```
skillhub install ppt-speech-fusion
```
或通过 URL 导入：`https://github.com/fulai223344-lang/ppt-speech-fusion`

### Marvis
```
skillhub install ppt-speech-fusion
```

## 使用

在 AI 助手中说：

- "把录音和PPT整理成演讲稿"
- "整理会议录音"
- "PPT配对话生成讲稿"
- "录音转演讲稿"
- "会议纪要配幻灯片"
- "汇报录音整理成逐页稿件"
- "对话转写+PPT输出PDF"

## 支持格式

- 音频：m4a / mp3 / wav
- 文档：pptx
